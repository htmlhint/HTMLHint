Special characters must be escaped.

Level: <Badge text="Error" variant="danger" />

## Config value

- `true`: enable rule
- `false`: disable rule

### The following patterns are **not** considered violations

```html
<span>aaa&gt;bbb&lt;ccc</span>
<span>Steinway &amp; Sons, Q&amp;A</span>
<span>Steinway & Sons, Q&A</span>
<span>&copy; 2026</span>
```

### The following patterns are considered violations

```html
<span>aaa>bbb<ccc</span>
<span>&copy 2026</span>
```

## Why this rule is important

Angle brackets in plain text can be read as HTML markup. Browsers can also decode some [character references](https://html.spec.whatwg.org/multipage/parsing.html#character-reference-state) without a semicolon. Write `&copy;` for © or `&amp;copy` to display the literal text `&copy`.
