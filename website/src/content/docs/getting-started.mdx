المحترمون جميعاً،،،
الموضوع: دراسة تمكين الموارد واستدامة التعافي وإدارة الأزمات بالمديرية (وفق فرضية التحفظ والواقعية 50%)
تحية طيبة وبعد،،،
نرفق لكم للدراسة والاطلاع والإقرار، النسخة المحدثة من دراسة "تمكين الموارد واستدامة التعافي وإدارة الأزمات — التشكيلة الاجتماعية للتعبئة العامة بمديرية بلاد الطعام".
وقد حرصنا في هذه النسخة على اعتماد سيناريو التحفظ والواقعية (تحقيق 50% فقط من الطاقة القصوى المتوقعة)، لضمان بناء موازنة تشغيلية آمنة ومضمونة قادرة على تغطية المتطلبات الميدانية بانتظام ودون مخاطرة، من خلال:

- تفعيل الموارد المحلية الرسمية وفق التشريعات القانونية وتوريدها بموجب السندات الرسمية (نموذج 50).
- تقنين المبادرات والأوعية المجتمعية والتكافلية بالتنسيق بين السلطة المحلية والمكاتب التنفيذية واللجان المجتمعية بمرونة وشفافية عالية.
  نأمل الاطلاع والتكرم بالتوجيه بتشكيل لجنة مشتركة لاستكمال إجراءات التقنين والتنفيذ وفق المخرجات والتوصيات المرفقة بالدراسة.
  وتقبلوا خالص التحية والتقدير،،،



🎯 أولاً: الرؤية والأهداف الإستراتيجية (الفرضية المعدلة)
تهدف هذه الدراسة إلى بناء نموذج تنموي ومالي آمن ومستدام يوفر تدفقات مالية نقدية منتظمة لدعم جهود إدارة الأزمات والأنشطة الميدانية بالمديرية، بالاعتماد على الحد الأدنى المضمون من التحصيل (50% كفرضية أساسية)، مما يقضي على العجز المالي ويضمن ديمومة الأعمال الاستراتيجية والخدمية.
🏛️ ثانياً: الأوعية المالية القانونية المعتمدة (100% رسمية — بفرضية 50%)

- رسوم تراخيص المهن ومزاولة النشاط التجاري:
  - السند القانوني: قانون السلطة المحلية (جدول الرسوم المحلية) وقانون الإثبات والمهن.
  - نطاق التحصيل: القطاع التجاري والخدمي بالمديرية (المحلات، الورش، خدمات التبريد، المقاهي).
  - الفرضية المعدلة (50%): استهداف 300 محل وبسطة (من أصل 600) بمتوسط تقديري يراعي التدرج الفئوي = 192,500 ريال شهرياً.
- إيرادات تنظيم ودخول الأسواق المحلية (الماشية والبضائع):
  - السند القانوني: لائحة تنظيم الأسواق العامة المرفقة بقانون السلطة المحلية.
  - نطاق التحصيل: سوق الماشية والأسواق الأسبوعية بالمديرية (سوق صرع وغيرها).
  - الفرضية المعدلة (50%): تحصيل على 200 رأس ماشية بدلاً عن 400 رأس = 200,000 ريال شهرياً.
- رسوم استغلال المحاجر والموارد الطبيعية (النيسة والأحجار):
  - السند القانوني: قانون المناجم والمحاجر وقانون الثروة المعدنية (حصة الموارد المشتركة).
  - نطاق التحصيل: وسائل النقل المحملة بالنيسة والأحجار ومواد البناء الإنشائية من الوديان والمقالع.
  - الفرضية المعدلة (50%): احتساب 40 حمولة شهرياً بواقع 1,500 ريال للحمولة = 60,000 ريال شهرياً.
- رسوم خدمات النظافة والتحسين:
  - السند القانوني: قانون صندوق النظافة والتحسين رقم (35) لسنة 1999م.
  - نطاق التحصيل: المحال التجارية، الأسواق العامة، ورخص البناء والتنمية بالمديرية.
  - الفرضية المعدلة (50%): استيفاء مبالغ مقطوعة محددة تعادل = 60,000 ريال شهرياً.
    🤝 ثالثاً: الأوعية المجتمعية والتنظيمية الخاصة (بفرضية 50%)
- صندوق دعم مزارعي الموز (مبادرة تكافل مجتمعي طوعي):
  - التكييف التنظيمي: دعم مالي طوعي موثق بموجب محضر اتفاق وتكافل بين السلطة المحلية ومزارعي وتجار الموز بوادي الكداري، يخصص لدعم أسر الشهداء والمجاهدين.
  - الفرضية المعدلة (50%): استقطاع 0.70 ريال عن كل حبة موز مباعة بإنتاج تقديري متحفظ (500,000 حبة شهرياً) = 350,000 ريال شهرياً.
  - الحوكمة: يدار عبر لجنة مجتمعية مستقلة وبسندات قبض خاصة غير رسمية لضمان صرفه في مصرفه المخصص.
- بند ترشيد المنظومات الشمسية وغرامات هدر المياه:
  - التكييف التنظيمي: استناداً إلى قانون المياه رقم (33) لسنة 2002م وقرارات السلطة المحلية لضبط استنزاف الأحواض المائية.
  - الفرضية المعدلة (50%):
    - تحصيل سند ترشيد وإشراف على 60 منظومة شمسية/مياه (بدلاً من 120) × 1,000 ريال = 60,000 ريال شهرياً.
    - تطبيق غرامات ضبط بيئي ومائي بمعدل (2.5 مخالفة شهرياً) = 25,000 ريال شهرياً.
- مساهمات المؤسسات والتأمين على العمالة:
  - التكييف التنظيمي: بالتنسيق مع مكتب الشؤون الاجتماعية والعمل لتأطير المستثمرين كمؤسسات وضمان السلامة المهنية والحقوق التشغيلية.
  - الفرضية المعدلة (50%): تغطية 14 عاملاً (بدلاً من 27) بواقع 250 ريالاً يومياً = 101,250 ريال شهرياً.

description: How to set up HTMLHint in your project by adding it as a dev dependency and configuring it.
---

import { Tabs, TabItem } from '@astrojs/starlight/components';

HTMLHint requires Node.js 22 or later.

1\. Use npm or yarn to install HTMLHint:

<Tabs>
  <TabItem label="npm">
`npm install --save-dev htmlhint`
  </TabItem>
  <TabItem label="yarn">
`yarn add --dev htmlhint`
  </TabItem>
</Tabs>

2\. Create a `.htmlhintrc` configuration file in the root of your project with `htmlhint --init`. This will create a file with default rules. You can customize it as needed. For example, you can use the following configuration to enforce some common best practices:

```json
{
  "alt-require": true,
  "attr-lowercase": true,
  "attr-no-duplication": true,
  "attr-value-double-quotes": true,
  "attr-value-no-duplication": true,
  "button-type-require": true,
  "doctype-first": true,
  "doctype-html5": true,
  "frame-title-require": true,
  "h1-require": true,
  "html-lang-require": true,
  "id-unique": true,
  "input-requires-label": true,
  "main-require": true,
  "meta-charset-require": true,
  "meta-description-require": true,
  "meta-viewport-require": true,
  "spec-char-escape": true,
  "src-not-empty": true,
  "tag-no-obsolete": true,
  "tag-pair": true,
  "tagname-lowercase": true,
  "title-require": true
}
```

3\. Run HTMLHint on, for example, all the HTML files in your project:

```shell
npx htmlhint "**/*.html"
```
